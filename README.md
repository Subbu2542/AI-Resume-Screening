# 🤖 AI Resume Screening & Interview Scheduling System

An AI-powered recruitment platform that automates resume screening, candidate evaluation, interview scheduling, recruiter analytics, and email generation using Google's Gemini AI.

---

## 🚀 Features

- 📄 Resume Parsing (PDF/DOCX)
- 🤖 AI Candidate Information Extraction
- 🎯 Resume vs Job Description Matching
- 📊 AI Match Score Calculation
- ✅ Automatic Candidate Shortlisting
- 👨‍💼 Recruiter Dashboard
- 📈 Recruitment Analytics
- 📅 Interview Scheduler
- 📧 Interview Email Generator
- 💾 SQLite Database Integration
- 📥 Candidate Report Download
